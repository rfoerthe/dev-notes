# Repository-Anweisungen

- Bei jeder Änderung der Projektversion in `package.json` und `package-lock.json` muss im selben Arbeitsschritt auch `changelog.md` um einen Eintrag für die neue Version ergänzt werden.
- Der Changelog-Eintrag enthält die Versionsnummer, das Datum und eine kurze Zusammenfassung der relevanten Änderungen.
